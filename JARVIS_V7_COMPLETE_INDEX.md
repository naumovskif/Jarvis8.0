## How to Start JARVIS v7.0

### Option 1: Run the Backend
```bash
python jarvis_backend.py
```

Then access:
- `http://localhost:8000` - Dashboard
- `http://localhost:8000/docs` - API documentation

### Option 2: Run Standalone
```bash
python main.py
```

### Option 3: Use Python API

#### Process a Request with Intelligence
```python
from jarvis_intelligence_engine import get_super_intelligent_jarvis

jarvis = get_super_intelligent_jarvis()
result = jarvis.process_request("Analyze system performance")
print(result)
```

#### Submit Autonomous Task
```python
from jarvis_autonomous_operations import get_autonomous_jarvis

jarvis_auto = get_autonomous_jarvis()
task_id = jarvis_auto.submit_autonomous_task(
    "Optimize database",
    priority="high"
)
result = jarvis_auto.autonomous_execute()
```
