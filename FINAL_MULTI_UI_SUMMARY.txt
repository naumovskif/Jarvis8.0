🎯 QUICK START (5 MINUTES)
================================================================================

OPTION 1: Windows Users
   1. Double-click: start_multi_ui.bat
   2. Watch 3 terminals open automatically
   3. Access: http://localhost:3000 (web) or terminal UI

OPTION 2: Manual Setup

   Terminal 1 - Backend:
   $ python jarvis_backend.py
   → http://localhost:8000

   Terminal 2 - Web Dashboard:
   $ npx create-next-app@latest jarvis-dashboard --typescript --tailwind
   $ cd jarvis-dashboard
   $ npm install axios recharts lucide-react
   (Copy component files from WEB_DASHBOARD_SETUP.md)
   $ npm run dev
   → http://localhost:3000

   Terminal 3 - Terminal UI:
   $ pip install textual rich
   $ python jarvis_terminal_ui.py
   → Beautiful TUI in terminal
